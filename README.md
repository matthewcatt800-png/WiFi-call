# WiFi-call

A small Wi-Fi calling project.

## Overview
This repository contains a Wi-Fi-call app build and related project files. The exact calling features and supported devices depend on the current implementation.

## Getting started
Review the included files and any device-specific notes before installing or testing. Android calling capabilities can depend on system permissions, hardware, network conditions and carrier support.

## Important
This project should not be assumed to replace your mobile carrier's supported calling service.

## Status
Experimental project; compatibility is not guaranteed.
